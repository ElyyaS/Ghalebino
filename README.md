# قالبی نو — مارکت‌پلیس قالب و محصولات وب

یک پلتفرم کامل مارکت‌پلیس چندفروشندگی (Multi-Vendor) برای خرید و فروش قالب‌های وب، به زبان فارسی و کاملاً راست‌چین (RTL).

> **نکته مهم:** محصول این پروژه، خودِ پلتفرم بازارچه است. قالب‌هایی که در بازارچه «فروخته می‌شوند»، محصولات خارجیِ فروشندگان هستند و سورس واقعی آن‌ها خارج از دامنه این پیاده‌سازی است. محصولات موجود در دمو، صرفاً رکوردهای دموی بازارچه هستند.

## پشته فناوری

- **Next.js 16** (App Router) + **React 19** + **TypeScript** (strict)
- **Tailwind CSS 4** (تم اختصاصی با فونت Vazirmatn)
- **PostgreSQL** + **Drizzle ORM**
- **Zod** برای اعتبارسنجی، **lucide-react** برای آیکون‌ها
- احراز هویت اختصاصی مبتنی بر session (کوکی httpOnly + هش scrypt)

## اجرا

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) تنظیم متغیرهای محیطی (کپی از .env.example)
#    DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db

# ۳) اعمال schema به دیتابیس
npx drizzle-kit push

# ۴) بارگذاری داده‌های دمو
npx tsx src/db/seed.ts

# ۵) اجرا در حالت توسعه
npm run dev

# ساخت و اجرای تولید
npm run build
npm run start
```

## قابلیت‌های اصلی

- **بازارچه:** جستجو (با پیشنهاد)، فیلتر پیشرفته، مرتب‌سازی، دسته‌بندی، تکنولوژی، مجموعه‌ها، فروشندگان
- **محصول:** گالری، لایسنس‌های چندگانه، دیدگاه‌ها با معیارهای امتیاز، پرسش و پاسخ، محصولات مشابه
- **مشتری:** سبد خرید، تسویه‌حساب، پرداخت (mock)، سفارش‌ها، دانلود محافظت‌شده، علاقه‌مندی، مقایسه، تیکت پشتیبانی، اعلان‌ها
- **فروشنده:** درخواست فروشندگی، مدیریت محصولات (پیش‌نویس → بررسی → انتشار)، داشبورد مالی (دفتر کل)، درخواست برداشت، پاسخ به دیدگاه/پرسش
- **مدیر:** مدیریت کاربران، بررسی فروشندگان، مدیریت (تأیید/رد/تعلیق) محصولات، دسته‌بندی/تکنولوژی، کد تخفیف، برداشت‌ها، گزارش‌ها، وبلاگ، تنظیمات
- **زیرساخت:** RBAC + بررسی مالکیت، لاگ ممیزی، انتزاع‌های Payment/Storage/Search/Email/Notification، سئو (sitemap, robots, metadata)

## ساختار پروژه

```
src/
├── app/                 # مسیرها (بازارچه، داشبوردها، ادمین، احراز هویت)
├── components/          # کامپوننت‌های UI، چیدمان، محصول، داشبورد
├── db/                  # schema، اتصال، seed
├── lib/                 # auth، قیمت‌گذاری، پرداخت، ذخیره‌سازی، جستجو، فرمت، اعتبارسنجی
└── server/              # لایه داده (queries) و server actions (mutations)
```
